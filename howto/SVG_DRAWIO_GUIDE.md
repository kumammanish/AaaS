# SVG & draw.io Integration Guide

**Azure Architecture Diagram Generator - Web Application**

---

##  Overview

The webapp now generates **SVG format by default**, making all diagrams fully editable in draw.io! This allows you to:

- Generate initial architecture from natural language
- Download as SVG
- Open in draw.io for further customization
- Add annotations, notes, and detailed styling
- Export in any format from draw.io (PNG, PDF, VSDX, etc.)

##  How to Use

### Step 1: Generate Diagram
1. Open http://localhost:5001
2. Enter your architecture description:
   ```
   Create a web app with SQL database and Redis cache
   ```
3. Click **Generate Diagram**
4. Format will default to **SVG (Editable in draw.io)**

### Step 2: Download SVG
- Click the **Download** button
- File will be saved as `azure_arch_YYYYMMDD_HHMMSS.svg`

### Step 3: Open in draw.io
1. Go to https://app.diagrams.net (draw.io)
2. Click **File → Open from → Device**
3. Select your downloaded SVG file
4. The architecture diagram will open with all components editable!

### Step 4: Customize (Optional)
In draw.io, you can:
- Move components around
- Resize elements
- Change colors and styles
- Add text annotations
- Add custom shapes
- Group elements
- Add backgrounds
- Export to other formats (PNG, PDF, VSDX, etc.)

##  SVG File Structure

### Generated SVG Contains
```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<!DOCTYPE svg PUBLIC "-//W3C//DTD SVG 1.1//EN"
 "http://www.w3.org/Graphics/SVG/1.1/DTD/svg11.dtd">
<!-- Generated by graphviz version 14.0.4 -->
<svg width="456pt" height="568pt"
 viewBox="0.00 0.00 456.00 568.00"
 xmlns="http://www.w3.org/2000/svg">

  <!-- Title -->
  <title>Architecture Description</title>

  <!-- Clusters (Layers) -->
  <g id="clust1" class="cluster">
    <title>cluster_Application Layer</title>
    <path fill="#ffe0b2" stroke="#aeb6be" d="..."/>
    <text>Application Layer</text>
  </g>

  <!-- Nodes (Azure Services) -->
  <g id="node1" class="node">
    <title>App Service</title>
    <image xlink:href="..." width="80" height="80"/>
  </g>

  <!-- Edges (Connections) -->
  <g id="edge1" class="edge">
    <path stroke="#000000" d="..."/>
    <text>Query</text>
  </g>
</svg>
```

### Key Elements
- **Clusters**: Color-coded layers (Frontend, Application, Data, etc.)
- **Nodes**: Azure service icons with labels
- **Edges**: Connections with labels (Query, Cache, HTTP/HTTPS, etc.)
- **Text**: Component names and layer names
- **Colors**: Layer-specific background colors

## 🔧 API Usage

### Generate SVG via API
```bash
curl -X POST http://localhost:5001/api/generate \
  -H "Content-Type: application/json" \
  -d '{
    "description": "Create a web app with SQL database",
    "format": "svg"
  }'
```

### Response
```json
{
    "success": true,
    "diagram_url": "/download/azure_arch_20251130_122842.svg",
    "metadata": {
        "components": 3,
        "format": "svg",
        "generated_at": "20251130_122842"
    }
}
```

### Download SVG
```bash
curl -O http://localhost:5001/download/azure_arch_20251130_122842.svg
```

##  Comparison: SVG vs PNG vs PDF

| Feature | SVG | PNG | PDF |
|---------|-----|-----|-----|
| **Editable** |  Yes (draw.io) |  No |  No |
| **Scalable** |  Infinite |  Pixelated |  Yes |
| **File Size** |  Small (5-20KB) | ⚠️ Medium (60-90KB) | ⚠️ Medium |
| **Web Display** |  Excellent |  Excellent | ⚠️ Requires viewer |
| **Print Quality** |  Perfect | ⚠️ Resolution-dependent |  Perfect |
| **Email Friendly** |  Small size | ⚠️ Larger size |  Universal |
| **Version Control** |  Text-based |  Binary |  Binary |
| **draw.io Compatible** |  Native |  Import only |  Import only |

**Recommendation**: Use **SVG** as primary format, export to PNG/PDF from draw.io if needed.

## ❓ FAQ

### Q: Can I convert SVG to PNG later?
**A**: Yes! Open SVG in draw.io and use **File → Export as → PNG**

### Q: Will my Azure service icons show in draw.io?
**A**: Yes, icons are embedded in the SVG as image references

### Q: Can I add custom Azure services in draw.io?
**A**: Yes, draw.io has extensive Azure shape libraries under **More Shapes → Azure**

### Q: What if the layout isn't perfect?
**A**: Open in draw.io and use **Arrange → Layout** for automatic reorganization

### Q: Can I use this for other clouds (AWS, GCP)?
**A**: Currently Azure-only, but architecture can be adapted in draw.io
